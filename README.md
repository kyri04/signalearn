# SignaLearn
SignaLearn is a Python library that keeps scientific analysis choices explicit
while handling routine implementation details.

Choose your data, preprocessing, models, and evaluation. SignaLearn handles
sample alignment, data loading, and metadata through a consistent interface,
helping researchers and AI agents inspect, modify, and reuse analyses.

## Install
Requires Python 3.11 or later. From the source checkout:

```sh
python -m pip install .
```

Import with `import signalearn as sl`.
