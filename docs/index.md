# SignaLearn
SignaLearn keeps scientific analysis choices explicit while handling routine
implementation details.

Choose your data, preprocessing, models, and evaluation. SignaLearn handles
sample alignment, loading, and metadata through a consistent Python interface.
These conventions help researchers and AI agents inspect, change, and reuse
analyses. Scientific validity still depends on the chosen methods and study design.
